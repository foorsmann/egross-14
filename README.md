# Custom Shopify Theme

This repository contains an original Shopify Online Store 2.0 theme built from the ground up. The codebase is intentionally minimal at this stage and will grow feature by feature.

## Development

- Install dependencies: `npm install`
- Format files: `npm run format`
- Lint theme: `npm run lint:theme`

## Structure

Key files delivered so far:

- `layout/theme.liquid` – base layout
- `sections/header.liquid` – header with mega menu
- `assets/mega-menu.css` & `assets/mega-menu.js` – styles and scripts for the menu
